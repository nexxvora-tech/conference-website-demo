# Nexxvora — Horizon Summit 2027 Conference Template

A responsive, dark editorial-style conference website starter with an interactive 3D hero (Three.js), 3D tilt cards, illustrated imagery, countdown timer, event tracks, speaker profiles, tabbed agenda, venue gallery, ticket tiers and a demo interest form. All event names, speakers and prices are fictional samples.

**Brand:** [Nexxvora](https://nexxvora.netlify.app/)

## Preview locally

1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.
3. For local development, use VS Code Live Server or any static file server.

## Included files

- `index.html` — page structure and sample event content
- `styles.css` — responsive styling, layout and decorative artwork
- `script.js` — mobile navigation, current year and demo form interaction
- `assets/nexxvora-mark.svg` — Nexxvora brand mark
- `assets/img/` — speaker, track and venue illustrations (SVG, replaceable)
- `assets/og-image.png` — social share preview
- `assets/vendor/three.min.js` — Three.js r128 (MIT) powering the 3D hero

## Customize before publishing

- Replace the sample event name, dates, venue, descriptions, speakers and agenda with accurate information.
- Replace speaker initials with photographs you own or have permission to use.
- Update the title, meta description and favicon if you rename the event.
- Connect the interest form to a secure backend or a registration service before collecting real attendee information.

## Important limitations

This is a **static front-end demo**. It does not include a database, admin dashboard, user authentication, payment processing, paper submission or server-side registration. The demo interest form does not send or store submitted information. The contact links open the Nexxvora website or the visitor's email application.

## Publish the free demo on GitHub Pages

1. Create a **public** repository in your Nexxvora GitHub account.
2. Extract this ZIP and upload the contents of the `nexxvora-conference-template` folder (including `assets/`, `index.html`, `styles.css` and `script.js`) to the repository root.
3. Commit the files to the `main` branch.
4. Open the repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

Before publishing, replace sample event dates, speaker names and schedule details with accurate content. Only publish assets you own or are licensed to use.
